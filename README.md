# AI-Assisted Career Skill Gap Analysis and Personalized Learning System

## 📌 Project Overview

An AI-assisted career guidance web application that helps students identify skill gaps based on their selected career and explore personalized learning plans to improve their skills.

## 🎯 Objectives

* Help students understand the skills required for their chosen careers.
* Identify missing skills and areas for improvement.
* Generate personalized learning plans.
* Provide study materials to support continuous learning.
* Track learning progress.

## ✨ Features

* Student profile management
* Career selection
* Career-specific skill gap analysis
* Personalized learning plans
* Study materials for learning topics
* Learning progress tracking
* About and Contact pages

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Flask
* **Database:** SQLite

## ⚙️ Installation and Setup

### Prerequisites

* Python 3.10 or later
* pip (Python package manager)

### Steps

1. Clone or download this repository.

2. Open a terminal in the project folder.

3. Install the required dependencies:

   ```bash
   python -m pip install -r requirements.txt
   ```

4. Start the application:

   ```bash
   python runserver.py
   ```

5. Open your browser and visit:

   `http://127.0.0.1:5000`

## 🎓 Project Purpose

This project demonstrates how a web application can support career planning by identifying skill gaps, organizing learning topics, and helping students track their learning progress.
